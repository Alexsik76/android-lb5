# Лабораторна робота № 5: Дослідження роботи з вбудованими датчиками

## Опис проекту
Цей проект реалізує функціональність **цифрового компаса** для платформи Android у межах виконання Лабораторної роботи №5. Додаток використовує вбудовані датчики пристрою для визначення орієнтації у просторі та візуалізації напрямку на північ.

## Виконання вимог task5.txt
Згідно з завданням (повний рівень, 20/20), у проекті реалізовано наступне:

1.  **Використання датчиків:** Програма відстежує зміни значень з двох датчиків одночасно:
    *   `Sensor.TYPE_ACCELEROMETER` (Акселерометр) — для визначення вектора сили тяжіння.
    *   `Sensor.TYPE_MAGNETIC_FIELD` (Магнітометр) — для визначення магнітного поля Землі.
2.  **Обробка даних:** 
    *   Використовується метод `SensorManager.getRotationMatrix` для отримання матриці повороту на основі даних з обох датчиків.
    *   Реалізовано перерахунок системи координат через `SensorManager.remapCoordinateSystem`, що дозволяє компасу працювати коректно при будь-якій орієнтації екрана (Portrait/Landscape).
    *   Метод `SensorManager.getOrientation` обчислює кут азимуту.
3.  **Візуалізація:**
    *   **Графічна:** Зображення стрілки компаса (`ivCompass`) динамічно обертається відповідно до отриманого азимуту.
    *   **Текстова:** Виводиться точне значення кута в градусах та назва сторони світу (N, NE, E, SE, S, SW, W, NW).

## Ключові класи та методи

### Класи
*   **`CompassFragment`**: Центральний компонент логіки. Реалізує інтерфейс `SensorEventListener`. Керує життєвим циклом датчиків (реєстрація в `onResume`, відписка в `onPause`) та оновлює елементи інтерфейсу.
*   **`CompassViewModel`**: Забезпечує архітектурно правильне збереження стану (азимуту) за допомогою `LiveData`, що дозволяє уникнути проблем при зміні конфігурації пристрою.
*   **`MainActivity`**: Точка входу, яка хостить `CompassFragment`.

### Методи
*   **`onSensorChanged(event: SensorEvent?)`**: Основний метод обробки подій від датчиків. Збирає сирі дані, перевіряє наявність значень з обох сенсорів та запускає розрахунок орієнтації.
*   **`updateAzimuth(newAzimuth: Float)`**: Метод у ViewModel для оновлення поточного значення, на яке підписаний фрагмент.
*   **`SensorManager.remapCoordinateSystem`**: Використовується для адаптації азимуту під поточний поворот вікна (`display.rotation`), що забезпечує стабільність показань компаса.
*   **`Math.toDegrees`**: Перетворює радіани, отримані від сенсорів, у градуси для зручності відображення.

## Як запустити
1. Відкрийте проект у Android Studio.
2. Запустіть додаток на фізичному пристрої (емулятори часто не підтримують магнітометр повноцінно).
3. Обертайте пристрій навколо вертикальної осі для перевірки роботи компаса.
